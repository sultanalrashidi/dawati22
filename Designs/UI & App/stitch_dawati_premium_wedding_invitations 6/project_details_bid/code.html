description Project Overview

We are seeking a master calligrapher and invitation designer for a high-profile luxury wedding in Dubai. The aesthetic should merge traditional Arabic artistry with contemporary minimalist design.

The suite must include a main invitation card, details insert, RSVP card, and custom envelope liners. The primary focus should be an exquisite, custom-designed monogram blending the initials of the bride and groom in a fluid, modern Arabic script.

Materials will ultimately be printed on heavy cotton stock with deep letterpress and blind embossing techniques, so the digital designs must be meticulously prepared for these high-end print processes.
